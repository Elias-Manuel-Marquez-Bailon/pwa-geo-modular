¿Cómo reactivar el permiso?
  • Chrome / Android: toca el ícono 🔒 junto a la URL → Permisos → Ubicación → Permitir.
  • Safari / iPhone: Ajustes → Safari → Ubicación → Preguntar o Permitir (en PWA instalada, revisa también Ajustes → Privacidad → Localización).
  • Firefox: ícono 🔒 → Borrar permisos y recargar.
